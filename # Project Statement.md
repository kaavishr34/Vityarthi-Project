# Project Statement

## 1. Problem Statement

Managing employee details and calculating salaries manually can take a lot of time and can also lead to mistakes.

This project provides a simple **Employee Payroll Management System** that helps manage employee information, attendance, salaries, and payroll calculations in one place.

## 2. Scope of the Project

The project is mainly focused on basic employee and payroll management. It allows the user to:

* Add, view, search, update, and delete employee details
* Record and check employee attendance
* Calculate employee salaries
* Calculate bonuses, incentives, and overtime pay
* Calculate deductions and net salary
* View payroll statistics
* Check department-wise payroll expenses
* Sort employees based on their salary
* Find the Employee of the Month
* Generate payroll reports and payslips
* Create a salary bar chart

The program is currently a **console-based application**, and employee information is stored only while the program is running.

## 3. Target Users

This project can be useful for:

* Small businesses
* Offices
* HR staff
* Payroll staff
* Managers
* Anyone who needs a simple way to manage employee and salary information

## 4. High-Level Features

### Employee Management

* Add and manage employee details
* Search employees by ID or name
* Update or delete employee records

### Attendance Management

* Record employee attendance
* View attendance details and percentages

### Payroll Management

* Calculate gross and net salary
* Calculate deductions
* Add bonuses, incentives, and overtime pay

### Payroll Reports

* View total and average payroll
* Check highest and lowest paid employees
* View department-wise expenses
* Generate full payroll reports and payslips

### Performance

* Find the Employee of the Month based on performance

### Salary Chart

* Display employee net salaries using a bar chart
