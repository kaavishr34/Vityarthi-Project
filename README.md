# Employee Payroll Management System

## 1. Overview of the Project

The **Employee Payroll Management System** is a Python-based, menu-driven application used to manage employee records, attendance, salaries, and payroll information. It allows users to perform employee management, calculate salaries, generate payroll reports and payslips, and analyze employee salary data.

## 2. Features

* Add, view, search, update, and delete employee records
* Search employees by ID or name
* Record and view employee attendance
* Calculate gross salary, deductions, and net salary
* Calculate department-specific bonuses and incentives
* View payroll statistics and department-wise expenses
* Sort employees by net salary
* Identify the Employee of the Month
* Generate full payroll reports and individual payslips
* Generate a net salary bar chart

## 3. Technologies/Tools Used

* **Python 3**
* **Matplotlib** – for generating the salary bar chart
* Python dictionaries, functions, loops, conditional statements, exception handling, and sorting

## 4. Steps to Install & Run the Project

### Prerequisites

* Install **Python 3**
* Install the required Matplotlib library:

```bash
pip install matplotlib
```

### Running the Project

1. Save the Python program in a `.py` file.
2. Open Command Prompt or Terminal.
3. Navigate to the project folder.
4. Run:

```bash
python filename.py
```

5. Use the displayed menu to select the required operation.

## 5. Instructions for Testing

Test the following functions to verify that the system works correctly:

1. **Add Employee** – Add employees from different departments.
2. **View/Search** – Check employee records using ID and name.
3. **Update/Delete** – Modify an employee record and test deletion.
4. **Attendance** – Record attendance and verify the attendance report.
5. **Salary Calculation** – Check gross salary, deductions, and net pay.
6. **Payroll Analysis** – Verify total payroll, average salary, highest/lowest paid employees, and department-wise expenses.
7. **Salary Chart** – Generate the net salary bar chart.
8. **Payslip** – Generate a payslip and check the displayed information.
9. **Invalid Input** – Try entering incorrect IDs, menu options, departments, or numbers and check whether the program gives the appropriate error message.

8. **Payslip** – Generate and verify an individual employee payslip.
9. **Invalid Input** – Test invalid menu choices, employee IDs, departments, and numeric inputs to ensure appropriate error messages are displayed.
